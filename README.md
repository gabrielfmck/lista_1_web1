# Lista 1 — Programação para Web I

Primeira lista de exercícios da disciplina **Programação para Web I**, do curso de Sistemas de Informação da **Universidade Federal de Uberlândia (UFU)**, semestre **2026/2**.

O projeto reúne exercícios de HTML, CSS e JavaScript organizados por aula. A página inicial funciona como um índice com acesso às 33 atividades.

## Tecnologias

- **HTML5:** estrutura das páginas, links, imagens, listas, tabelas e mapas de imagem.
- **CSS3:** cores, bordas, alinhamento, tipografia, efeitos de hover, posicionamento absoluto, sobreposição, Flexbox e Grid.
- **JavaScript:** manipulação do DOM e interações com botões.

## Conteúdo

| Aula | Atividades | Assuntos |
| --- | --- | --- |
| [02_2](aula02_2/) | 6 | Dados do aluno, links externos, PDF, imagens como links e caminhos relativos. |
| [03](aula03/) | 10 | Listas, página pessoal, tabelas, `colspan`, `rowspan` e realce com hover. |
| [04](aula04/) | 9 | Mapas de imagem, favicon, CSS incorporado e externo, bordas, alinhamento, decoração de texto e imagem de fundo. |
| [05_2](aula05_2/) | 3 | Posicionamento absoluto e sobreposição de blocos conforme os três modelos da aula. |
| [06](aula06/) | 2 | Organização de elementos com Flexbox e CSS Grid. |
| [07](aula07/) | 3 | Alterar a cor de um parágrafo, adicionar itens a uma lista e ocultar ou exibir parágrafos. |

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/gabrielfmck/lista_1_web1.git
   cd lista_1_web1
   ```

   Você também pode baixar o ZIP pelo botão **Code → Download ZIP** no GitHub e extrair os arquivos.

2. Abra o arquivo [`index.html`](index.html) no navegador.
3. Escolha uma aula e clique no exercício que deseja visualizar.

O projeto é estático e pode ser aberto diretamente no navegador, sem instalar dependências ou configurar um servidor. Mantenha a estrutura das pastas para que os links, imagens e estilos sejam carregados corretamente. Links para sites externos precisam de conexão com a internet.
